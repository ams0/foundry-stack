# foundry

Composable Terraform modules for deploying **Azure AI Foundry** — Hub, projects, model deployments — together with the storage, search, networking, gateway, and observability stack you usually want around it.

> The repo is HCL only. Two reference root modules (`examples/minimal`, `examples/complete`) wire the leaf modules into a working deployment.

---

## What you get

The `complete` example deploys:

| Layer | Module | Notes |
|---|---|---|
| Networking | `networking` | VNet, per-service subnets, private DNS zones (off by default) |
| Observability | `monitoring` | Log Analytics + Application Insights, auto-attached diagnostics |
| Data | `storage`, `search`, `keyvault` | Required by Foundry Hub |
| Data (optional) | `redis`, `cosmosdb` | Model caching, agent state |
| AI | `foundry` | AI Services (S0) + Foundry Hub + Project + model deployments (gpt-5, text-embedding-3-large by default) |
| AI | `rbac` | Grants Hub/AI-Services managed identities access to storage, search, KV, redis |
| Gateway (optional) | `apim` | API Management in front of Foundry |
| Gateway (optional) | `litellm` | LiteLLM proxy on Container Apps, MI → `Cognitive Services OpenAI User` |
| Gateway (optional) | `openclaw` | OpenClaw coding agent (Container App), reuses LiteLLM's environment |
| Portal | `dashboard` | Azure Portal dashboard surfacing the stack |

The `minimal` example is the smallest viable Foundry stack: networking + monitoring + storage + search + keyvault + foundry + rbac.

## Requirements

- Terraform `>= 1.9`
- An Azure subscription and a working `az login`
- Providers (pinned in `versions.tf`):
  - `hashicorp/azurerm` `~> 4.64`
  - `azure/azapi` `~> 2.8`
  - `hashicorp/random` `~> 3.8`

## Quick start

```sh
# Pick an example: complete (default) or minimal
make init EXAMPLE=minimal
make plan EXAMPLE=minimal
make apply EXAMPLE=minimal
```

Configure inputs in `examples/<name>/terraform.tfvars` (copy from `terraform.tfvars.example` in `complete`). Key knobs:

```hcl
name_prefix               = "foundry"
location                  = "swedencentral"
enable_private_networking = false           # flip on for private endpoints + DNS
allowed_ips               = ["1.2.3.4"]     # public-access IP allowlist (ignored when private networking is on)

# Optional layers (complete example only)
enable_redis    = false
enable_apim     = false
enable_litellm  = false
enable_cosmosdb = false
enable_openclaw = false    # requires enable_litellm = true
```

After apply, useful outputs include `foundry_portal_url`, `ai_services_endpoint`, `apim_gateway_url`, `litellm_endpoint`, `openclaw_url`, `dashboard_url`, and `estimated_monthly_cost`.

## Common commands

```sh
make help          # list targets
make validate      # init -backend=false + validate for every module and example
make fmt           # terraform fmt -recursive .
make fmt-check     # check formatting without modifying
make docs          # regenerate per-module README.md via terraform-docs
make destroy       # tear down the selected example
make clean         # remove .terraform dirs and lock files
```

`EXAMPLE=minimal|complete` selects which example `init`/`plan`/`apply`/`destroy` operates against.

Each module follows the same file layout: `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf`, optional `private_endpoint.tf`, and a `README.md` regenerated by `make docs`.

## Design notes

- **Optional modules** expose `enable_<name>` and gate every resource with `count`. Outputs are wired unconditionally — disabled modules return `null` shapes.
- **Private networking is one switch.** `enable_private_networking = true` disables public access on each service, switches default actions to `Deny`, and provisions private endpoints + DNS. `allowed_ips` is intentionally ignored in that mode.
- **Naming**: examples compose `name_prefix = "<your-prefix>-<random suffix>"` so reruns are stable but parallel deploys don't collide.
- **AzAPI for Foundry**: AI Services is created via `azapi_resource` because `azurerm_ai_services` doesn't expose `allowProjectManagement`, which the new Foundry portal requires.
- **Policy exemption**: `foundry` accepts `policy_exemption_policy_assignment_id` to exempt the Hub from management-group policies that force `publicNetworkAccess=Disabled`.
- **Cost estimation**: `examples/complete` computes an `estimated_monthly_cost` output (Sweden Central base infrastructure, excludes API/token usage).
